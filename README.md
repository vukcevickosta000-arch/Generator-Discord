# Bloodfall: War of the Ancients

An original dark-fantasy **MOBA** (with a planned Warcraft-style **RTS** mode) for Windows PC.

It comprises:

- a Unity 6 client
- an authoritative dedicated game server
- an ASP.NET Core backend for accounts, social, lobbies, matchmaking, statistics and content
- a shared, engine-independent C# simulation used by the client (offline practice), the server and the tests

Classic MOBA feel (in the tradition of Heroes of Newerth) with entirely original names, lore, art, data and code.

> **Status:** early development. See [PROJECT_STATUS.md](PROJECT_STATUS.md) for exactly what works and what does not.

## Repository layout

| Path | Contents |
|---|---|
| `Shared/` | Engine-independent C# (netstandard2.1). It is compiled by the server and imported by Unity as the local package `com.bloodfall.shared`. It contains the simulation, network protocol, API contracts and game data (`Runtime/Resources/GameData/*.json`). |
| `Server/src/Bloodfall.Backend` | ASP.NET Core 8 services: auth, accounts, social, clans, lobbies, matchmaking, directory, stats, content, and a WebSocket realtime hub. |
| `Server/src/Bloodfall.GameServer` | Dedicated authoritative match server (LiteNetLib UDP). |
| `Server/tests` | xUnit tests: simulation, protocol, data. |
| `Server/tools` | `Bloodfall.SimRunner` (headless bot matches) and `Bloodfall.E2E` (end-to-end online test). |
| `Client/` | Unity 6 (6000.0.40f1, URP) project: the entire client is built in code from `Assets/Scripts` (see Docs/TECHNICAL_ARCHITECTURE.md). |
| `Tools/mapgen` | Velmoragh map generator (nav grid, heightfield, splat maps, dressing, layout preview). |
| `Tools/art` | Procedural 2D art generators: UI kit, menu backdrop, VFX sprites, terrain textures. |
| `Tools/dev` | Local stack scripts (`run-local.sh`, `run-e2e.sh`, …). |
| `Tools/UnityCompileCheck` | Headless compile check of the Unity client and editor scripts against Unity reference assemblies. |
| `Docs/` | Design and architecture documentation. |

## Quick start

```bash
# Server: build + tests
dotnet build Server/Bloodfall.sln
dotnet test Server/tests/Bloodfall.Tests

# Full local stack (backend on :5080 + 2 game servers on UDP 27015-27016)
Tools/dev/run-local.sh
curl http://localhost:5080/api/content/status
Tools/dev/stop-local.sh

# End-to-end online test (fresh database, real UDP match)
Tools/dev/run-e2e.sh

# Headless 20-minute 5v5 bot match
dotnet run -c Release --project Server/tools/Bloodfall.SimRunner -- 20 11
```

To start the Unity client:

1. Open `Client/` in **Unity 6000.0.40f1**.
2. Run **Bloodfall ▸ Setup Project**. It runs automatically on first open when no render pipeline is set.
3. Press Play in any scene.

The client connects to `http://localhost:5080` by default. Without a running backend, choose **Play Offline** for
practice against bots. Full instructions are in [Docs/BUILD_INSTRUCTIONS.md](Docs/BUILD_INSTRUCTIONS.md).
